# Coleção Nuvio Portugal

Pacote gratuito e nativo para o Nuvio, configurado para Portugal.

## Incluído

- Explorar por 10 serviços de streaming, com separação entre Filmes e Séries.
- Filmes recentes, populares e em breve.
- Séries recentes, populares e em breve.
- Categorias com separação entre Filmes e Séries.
- Banners horizontais com fundo visual uniforme.

## Requisito gratuito

As fontes usam o TMDB Discover nativo do Nuvio. É necessário criar uma chave gratuita em https://www.themoviedb.org/settings/api e adicioná-la nas definições TMDB do Nuvio.

## Instalação

1. Publique esta pasta num repositório GitHub público chamado `nuvio-colecao-pt`.
2. No Nuvio, abra as Coleções e escolha Importar por URL.
3. Utilize `https://raw.githubusercontent.com/giriadabola/nuvio-colecao-pt/main/collections.json`.

## Nota

O TMDB controla a disponibilidade regional. Os resultados são filtrados para `PT`, mas podem existir atrasos ou falhas nos dados de determinados serviços. As datas de “recentes” e “em breve” devem ser atualizadas periodicamente no ficheiro JSON.
